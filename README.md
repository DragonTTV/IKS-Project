# Lesser Known Indian Musical Instruments 

This is an interactive 3D website built for our IKS project with the topic of : <b>Lesser Known Indian Musical Intruments</b><br>
We are still freshers and this was our first web development project and this was also done on a time crunch so please give your feedback and ideas for additions or improvements we can make here.<br>

A 3D web experience showcasing the unknown and obscure musical instruments of India.This immersive page aims to educate the modern audiences about the rich musical history and traditions of India.<br>
## Features:-
-Clickable 3D models of the instruments<br>
-Digitally designed Infocards describing the instruments and their history<br>
-Playable audio demonstrating the sounds of the instruments<br>
-Use of self-modeled as well as publically available 3D assets<br>

## Technical Stack:- 
-Programmed using JavaScript <br>
-Used the 3D library of JavaScript [Three.js]<br>
-Built on Vite<br>
-Source control using Git remote repository<br>
-Modelled and edited 3D assets using Blender<br>
-Implemented Html and CSS for basic styling<br>
-Deployed on Git pages<br>
